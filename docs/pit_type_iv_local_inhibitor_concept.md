## Type IV で何が足りないか

Kudo Type IV は、脳溝様の **branching / gyrus-like** な pit 模様として理解される。Gray-Scott 型モデルでは、適切な `(f, k)` で labyrinth（ストライプ）相に入ると、一見 Type IV に近い網目が出る。

しかしそのままでは、次のような morphology になりやすい。

- 画面を横断する **1 枚の巨大な迷路状ストライプ** が支配的になる。
- skeleton 上では分岐点（赤）の数自体は多いが、それらが **1 つの連結ネットワーク** に束ねられている。
- 期待する「短い枝が何本も立ち上がる樹状構造」より、「空間が尽きるまで伸びてから凍結した網」に近い。

このギャップを、幾何で枝を描くのではなく **成長の力学そのもの** を変えることで埋めたい。

---

## 問題の診断：なぜ線は「伸び続ける」のか

Gray-Scott の labyrinth は、ざっくり言えば **B-rich 状態が A-rich 領域へ侵入する双安定フロントの集合** として読める。長い線が安定しすぎる理由は、次の 2 点に集約できる。

### 1. 侵入モード（先端が前進し続ける）

Type IV 候補の `(f, k)` では、B 網が A 領域へ **正の侵入速度** \(v_0 > 0\) を持つ領域にいる。フロント同士はマージしにくく、空間を埋めるまで曲がりくねって伸び、衝突して凍結する。結果として **labyrinth 1 枚** が残る。

### 2. 長さスケールの欠如

モデルは本質的に **A と B の 2 変数** である。「この線はもう十分長いから止まれ」と言う内部変数がない。成長は **境界・他線との衝突・数値的飽和** が起きるまで続く。これが「伸び続ける方向に安定しすぎる」という直感の数式側の対応である。

```text
  現状の力学イメージ

  [B-rich ストライプ] ----侵入----> [A-rich 基質]
         |                              ^
         |  曲率・拡散でわずかに曲がる   |  feed で A が補充
         v                              |
    空間が尽きる / 他線と衝突するまで前進
    → 長い迷路が「自然な終着点」になる
```

## Step 0〜3 で分かったこと（対症療法の限界）

`evaluate_pit_steps.py` の Step 0〜3 は、いずれも **B の濃度や反応強度を直接いじる** 方向だった。

| 系統 | やっていること | 起きやすい結果 |
|------|----------------|----------------|
| Step 1 / 1b / 1c | 反応の飽和、\(B^3\) 減衰、芯だけの減衰 | 長い迷路は弱まるが、強めすぎると **枝ごと消えた孤立片** になる |
| Step 2 | 静的な \(f,k\) の空間ムラ（環境 C） | 局所で伸び方が変わるが、**1 枚の長い網** の骨格は残りやすい |
| Step 3 | B に追従する遅い環境 C | regime の混在（VI 寄り）には有効だが、**速い側方抑制** ではない |

定量比較（seed=7, 3500 steps, size 160）では、次の **トレードオフ** がはっきりした。

- **step0 baseline**: `longest_component_fraction ≈ 0.83` — 巨大迷路が支配的。
- **step1 飽和**: 迷路は短くなるが、まだ単一成分の支配は残る。
- **step1c_a 強い cubic**: `longest` は下がるが `branch_per_component` も下がり、**短いが枝のないダッシュ** に寄る。

つまり「B を弱める」だけでは、

```text
  巨大迷路  ←——調整——→  孤立片（枝なし）
```

の往復に留まり、目標の **「短い + 枝のある樹状」** の領域に入りにくい。

**教訓**: 必要なのは B の「強さ」を下げることだけではなく、**成長に内在する長さスケール** をモデルに足すことである。

## 新しい試みのコンセプト：局所インヒビター場 H

### 核となるアイデア

形態形成（肺・血管・腺管など）では、成長中の先端が **拡散性のインヒビター** を出し、近傍の成長を抑えることで、迷路状ではなく **間隔を持った樹状分岐** ができる。

これを Gray-Scott に持ち込む。第 3 の変数 **H** を次のように定義する。

```text
A_t = dA ∇²A − R(A,B) + f(1−A)

B_t = dB ∇²B + R(A,B) − (k+f)B − γ B H

H_t = dH ∇²H + ρ B − δ H
```

記号の意味:

| 記号 | 役割 |
|------|------|
| `H` | B から生成される、**速く・広く** 拡散する抑制物質 |
| `ρ B` | B-rich 領域（とくにストライプ・先端）が H を供給する |
| `δ H` | H の自然減衰（蓄積しすぎて全滅しないよう重要） |
| `γ B H` | 局所の H が B の増殖・維持を抑える（側方抑制） |

**設計上の要点** は、Step 3 の環境場 `C` とは役割を分けることである。

| | 環境場 `C` (Step 2/3) | インヒビター `H` (Step 4) |
|--|----------------------|---------------------------|
| 時間スケール | 遅い（`env_rate` が小さい） | 速い（毎 step と同程度に更新） |
| 空間スケール | 広い相関（滑らかなノイズ） | B に密着しつつ **拡散で広がる雲** |
| 結合 | \(f,k\) を変える（パラメータ空間を動かす） | **B の反応項を直接抑制** |
| 意図 | regime の空間的共存（VI 寄り） | **ストライプ間の間隔・先端の失速** |

`C` は「どの反応拡散相にいるか」をゆらす。**H** は「今伸びている線の周りに、もう伸びるなという局所信号を立てる」。

### 期待される力学

1. B-rich ストライプが H を出す。
2. H が拡散して周囲に広がり、近くの B 成長を抑える。
3. 別のストライプや **自分の先端** が、自分が作った H の「影」に入ると失速する。
4. その結果、**特徴的な間隔（長さスケール）** が生じ、伸び続ける 1 本の網ではなく、**分断・停止・分岐** が起きやすくなる。

```text
  H 導入後のイメージ

      B ストライプ
         |
         +---> H が生成・拡散
         |         \
         |          v  γBH で抑制
    [先端] ----?---- [H の雲]
         |
    前進が鈍る → 曲がる / 止まる / 別方向へ分岐
```

### パラメータ調整で学んだこと

H は **強すぎると B が全滅** する。長時間積分では H が空間全体に溜まり、γBH が系全体を殺す。初期の強い設定（大きな γ, ρ）は短期 smoke では生きて見えても、3500 step では `binary_coverage = 0` になった。

生存しつつ迷路を崩すには、**弱い生成・十分な減衰** が必要である。現行の `step4_pit_iv_inhibitor` は次のオーダーである（詳細は `evaluate_pit_steps.py` の `build_suite` を参照）。

- `γ`（inhibitor_strength）: 小さめ（例 0.05）
- `dH`（inhibitor_diffusion）: B より大きい（例 0.6）
- `ρ`（inhibitor_source）: 小さめ（例 0.05）
- `δ`（inhibitor_decay）: やや大きめ（例 0.10）— 蓄積を防ぐ

`step4b` は弱い cubic を併用する variant だが、併用すると **孤立片寄り** になりやすく、純 H の `step4` の方が「短い樹状」に近い傾向が出た。

## 成功条件（何をもって改善とみなすか）

単一指標では判断しない。次を **同時に** 満たす方向を Type IV 改善の候補とする。

### morphology 上の目標

- 1 枚の巨大 labyrinth が支配的でない（線が **分断** されている）。
- 分断された各成分が **分岐点を持つ**（孤立ダッシュだけではない）。
- セグメント長が、baseline より短いか、少なくとも「無限に伸びた 1 本」ではない。

### 指標での対応（[`pit_model_evaluation.md`](pit_model_evaluation.md) 参照）

| 指標 | 改善の目安 | 避けたいパターン |
|------|------------|------------------|
| `longest_component_fraction` | baseline (≈0.83) より **明確に低下** | 0 に近い（全滅） |
| `branch_density` | junction クラスタから 3 廊下が十分な長さで伸びる fork の密度 | 0（枝なし） |
| `branch_per_component` | **中程度以上**（樹状） | ≈0（孤立片）、極端に高いだけ（巨大迷路の局所密度） |
| `mean_segment_length` | 必要に応じて低下 | 極端に短く branch も無い |
| `long_line_score` | 低下 | — |

参考: 調整後の `step4_pit_iv_inhibitor`（同一 IC）では、おおよそ `longest ≈ 0.11`、`branch_density ≈ 0.27`、`branch_per_component ≈ 6.8`、`coverage ≈ 0.30` — baseline の迷路支配を解きつつ pattern は生存している。

### 画像での確認

`skeleton` オーバレイで、

- 赤（branch）が **複数の連結成分** に分散していること、
- シアン（endpoint）ばかりで赤が無い **ダッシュ列** になっていないこと、

を `contact_sheet.png` と並べて見る。

## 追補: Step 5（提案 W / M）— 幅・被覆の分離

H（Step 4）で **間隔・長さスケール** を入れたあと、別要因として **stripe の幅が `(f, k)` に吸収される** 問題が明確になった。これに対する **提案 W（bistable plateau）** のコンセプト・数式・パラメータ・実測は、専用メモ [`pit_type_iv_bistable_width_concept.md`](pit_type_iv_bistable_width_concept.md) にまとめた。

本稿との関係:

| 記号 | 役割 | 主な step |
|------|------|-----------|
| **H** | 間隔・先端失速（側方抑制） | Step 4 |
| **W** | 幅・振幅（双安定 plateau） | Step 5 |
| **M** | 被覆率（大域 feed フィードバック） | Step 5c |

要点のみ: **W 単体** が被覆 ~0.31 のまま `longest` を 0.83→0.33 に下げ、3 股分岐を保持。H を強く足すと分岐が潰れやすいので、W を主役にし H は弱めに。

## 今後の延長（コンセプト上の次の一手）

本稿の試みは **Step 4 = H のみ** を主役にした。まだ検証途中の方向として、次を置いておく。

1. **H + 弱い動的 C**  
   長さスケール（H）で線を短くしつつ、環境 C で局所 regime をずらし VI 不整（複数相の共存）を狙う。

2. **不応（refractory）場**（未実装）  
   B の滞在を時間積分し、古い芯だけ kill を上げる。H・bistable W とは別系統で「先端は生き、背後だけ死ぬ」力学。

3. **動作点の微調整（Maxwell 点近傍）**  
   新変数なしで侵入速度 \(v_0 \to 0\) に寄せ、H と組み合わせてパラメータ窓を広げる。

4. **指標の時間発展**  
   最終形だけでなく snapshot 列で「いつ迷路が分断されたか」を追う。

## まとめ

今回の新しい試みは、「Type IV らしい網目を **もっと描く**」のではなく、**伸び続ける力学そのものに長さスケールを与える** ことである。

- **問題**: 2 変数 Gray-Scott の labyrinth は、侵入するフロントが空間を埋めるまで伸び、1 枚の長い網になりやすい。
- **限界**: 飽和・cubic・環境 C は有用だが、多くが B を弱める対症療法で、「短い + 枝あり」と「巨大迷路 / 孤立片」の間を往復しやすい。
- **提案 1（Step 4）**: B 由来の速い局所インヒビター **H** を追加し、側方抑制で間隔と先端失速を生じさせる。
- **提案 2（Step 5）**: 幅を **bistable plateau (W)** で固定（詳細は [`pit_type_iv_bistable_width_concept.md`](pit_type_iv_bistable_width_concept.md)）。実測では **W 単体**が被覆一定のまま迷路分断と 3 股分岐保持を最もよく両立した。
- **成功**: `longest_component_fraction` の低下と `branch_density`・`branch_per_component` の維持を両立し、skeleton 上で **短い樹状** に見えること。

この方針が型として機能すれば、同じ枠組みで VI（局所 regime 共存）へ拡張する足場になる。
