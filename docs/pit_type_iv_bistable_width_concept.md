# Type IV の stripe 幅制御 — 提案 W（bistable plateau）

## この文書の位置づけ

[`pit_type_iv_local_inhibitor_concept.md`](pit_type_iv_local_inhibitor_concept.md) は、**長さスケール（間隔）** を与える局所インヒビター **H**（Step 4）を主題にした設計メモである。

本稿は、別系統の課題 — **stripe の「太さ」が `(f, k)` の調整を吸収してしまい、分岐などの topology 変化が出にくい** — に対する **提案 W（bistable plateau）** のコンセプト、数式、パラメータ、実測結果をまとめた設計メモである。

評価手順・step 定義の一覧は [`pit_model_evaluation.md`](pit_model_evaluation.md) を参照。

---

## 実験の立場（共通前提）

- pit の形をマスクで与えず、**反応拡散の式と係数だけ**から pattern を生じさせる。
- 同じ初期ゆらぎ（`make_initial_state`）から出発し、差分は数式とパラメータに限定する。
- 医学的 Kudo 判定の自動化ではなく、morphology が式変更でどう変わるかを比較する基盤である。

---

## 何が問題か：幅という「やわらかいモード」

Gray-Scott 型の labyrinth 相では、パラメータ `(f, k)` を動かすと、見た目上は次のような変化が **同時に** 起きやすい。

| 見た目の変化 | 数式上の対応（ざっくり） |
|--------------|--------------------------|
| pit / stripe が太くなる・細くなる | B-rich 領域の **幅・振幅** |
| 模様全体の面積割合 | **被覆率**（平均 B） |
| 線の間隔・波長 | **長さスケール** |
| 分岐・曲がり・断片化 | **topology** |

interactive に `feed` や `k` を動かすと、まず **太さ** が変わり、その結果として A/B の局所比や界面の曲率も変わる。ユーザー観察としては、「理想的な少し伸びた pit や分岐 pit」を狙う前に、**太さの調整にパラメータ探索が使い切られる** という現象が起きる。

これを次のように言い換える。

```text
  (f, k) の摂動
       |
       +---> 幅・振幅（やわらかいモード）  ← 吸収されやすい
       |
       +---> 分岐・停止・topology（狙いたい方向）  ← 届きにくい
```

Step 1〜1c の飽和・cubic は **B の濃度を下げる対症療法** であり、幅を `(f, k)` から切り離す設計ではない。Step 4 の **H** は **間隔・先端失速（長さスケール）** を与えるが、幅の双安定化とは別チャンネルである。

**提案 W の目的**: stripe の **on 状態の濃度と界面幅** を `(f, k)` ではなく専用の非線形項で固定し、残りのパラメータ変動を **topology** に流す。

---

## 提案 W：bistable plateau

### 追加する項

Gray-Scott の `B` 方程式に、次の cubic 項を足す。

```text
B_t = dB ∇²B + R(A,B) − (k+f)B + λ B (1−B) (B−β)
```

コード上の名前（`ModelConfig`）:

| 記号 | フィールド名 | 意味 |
|------|--------------|------|
| λ | `bistable_strength` | 双安定の強さ。大きいほど B が 0/1 に張り付く |
| β | `bistable_threshold` | 中間しきい値。安定盆地の境界の位置 |

`R(A,B)` は従来どおり（飽和ありなら `AB²/(1+qB²)` など）。H や M を併用する variant では、それらの項がこの式に加わる。

### 力学の読み方

項 `λ B (1−B) (B−β)` は、**1 変数の双安定反応** と同型である。

- **B = 0**: 安定（B が無い相）
- **B = 1**: 安定（B-rich の plateau）
- **B = β**: 不安定（界面付近）

拡散 `dB ∇²B` と組み合わさると、B-rich 領域は **ほぼ一定濃度 B ≈ 1 の芯** と、幅 ~ `w` の遷移層からなる stripe になる。古典的には、弱い双安定系の界面幅は概ね

```text
w ~ sqrt( dB / λ )
```

のオーダーで、`f` や `k` より **`dB` と `λ`（と界面形状を決める `β`）** で幅が決まる。

```text
  提案 W のイメージ

  従来:  (f,k) ──> 幅・振幅・被覆・波長・形  （全部つながっている）

  W 後:  λ, β, dB ──> 幅・振幅（plateau B=1 に固定）
         (f,k)     ──> 侵入・分岐・断片化など（topology 寄り）
```

### Step 1b の cubic との違い

| | Step 1b `−μ B³` | 提案 W `+λ B(1−B)(B−β)` |
|--|------------------|-------------------------|
| 符号・形 | 常に B を減衰させるペナルティ | **0 と 1 の両方を安定** にする |
| 目的 | 高 B の芯を弱める（対症療法） | **on 濃度を 1 にピン留め**、幅を別パラメータ化 |
| 典型結果 | 迷路は短くなるが孤立片化しやすい | 被覆を保ちつつ迷路を **分断**、3 股分岐を残しやすい |

どちらも B の 3 次式を使うが、**符号構造と安定点の数** が異なる。W は「弱める」ではなく **幅という自由度を別チャンネルに切り出す** ための項である。

## H（Step 4）・M（Step 5c）との役割分担

3 つの「固定したい尺度」と、対応するメカニズムを分けて考える。

| チャンネル | 制御したいもの | メカニズム | Step |
|------------|----------------|------------|------|
| **W** | stripe の **幅・振幅** | bistable plateau | `step5` |
| **H** | 線間の **間隔・先端失速** | 局所インヒビター | `step4` / `step5b` |
| **M** | 画面全体の **被覆率** | `f_eff = f + κ(φ* − ⟨B⟩)` | `step5c` |

```text
  自由度を閉じる順序（設計上の理想）

  W で幅を固定 → H で間隔を固定 → M で被覆を固定
  → 残りは topology（分岐・伸長・断片化）だけ
```

実測では **W 単体** が最もバランスが良く、H を強く重ねると分岐が再び潰れる（後述）。W は H の代替ではなく、**直交する第 2 軸** として扱う。

## 評価スイートと推奨パラメータ

`evaluate_pit_steps.py` の `build_suite` に定義されている。

| case | 内容 | 主な係数（例） |
|------|------|----------------|
| `step5_pit_iv_bistable_width` | **W のみ** | `λ=0.10`, `β=0.22`, `f=0.033`, `k=0.056` |
| `step5b_pit_iv_bistable_inhibitor` | W + 弱い H | 上記 + `γ=0.03`, `ρ=0.04`, `δ=0.12`, `dH=0.6` |
| `step5c_pit_iv_three_channel` | W + H + M | 上記 + `κ=0.05`, `φ*=0.30` |

`β` のスイープでは、小さすぎると plateau が崩れ迷路化し、大きすぎると B が立ちにくくなる。**β ≈ 0.22, λ ≈ 0.10** は、size=160・3500 steps・seed=7 で「被覆 ~0.31 を保ちつつ `longest` を下げ、3 股分岐を残す」領域に入った。

### パラメータ調整の目安

- **`bistable_strength` (λ)**  
  - 上げる: B が 0/1 に張り付き、幅は狭くなりやすい（`w ~ 1/√λ`）。  
  - 上げすぎ: pattern 全滅や spot のみ、分岐消失。  
  - 下げる: 従来 Gray-Scott に近づき、幅が再び `(f,k)` に引っ張られる。

- **`bistable_threshold` (β)**  
  - 双安定の「中間の丘」の位置。界面の生成・維持に効く。  
  - 実験では **0.22 前後** が、β=0.30 より分岐・分断のバランスが良かった。

- **`d_b`**  
  - 界面幅のスケール `sqrt(dB/λ)` の分子。W とセットで幅を決める。

- **`feed`, `k`**  
  - W 導入後は、主に **侵入・分岐・被覆の微調整** 用として残す（太さの主ノブではなくなる）。

## 実測結果（同一 IC, size=160, steps=3500, seed=7）

被覆率 `binary_coverage` を ~0.31 に揃えた比較。

| variant | longest | branch (3-arm) | br/comp | 解釈 |
|---------|---------|----------------|---------|------|
| step0 baseline | 0.83 | 86 | 6.1 | 巨大迷路が支配 |
| step4 H 単体 | 0.11 | 0 | 0.0 | 迷路は崩れるが **断片化**、厳密 3 股は消失 |
| **step5 W 単体** | **0.33** | **26** | **1.4** | 迷路を **分断** しつつ 3 股を **保持** |
| step5b W+H | 0.18 | 0 | 0.0 | H が強すぎて分岐を潰す |
| step5c W+H+M | 0.23 | 20 | 0.8 | W と H の中間 |

読み方:

1. **W 単体** が、Type IV 改善の指標で最もバランスが良い — `longest` を baseline 0.83 から 0.33 へ下げながら、`branch` と `br/comp` を維持。
2. H だけでは「短いが枝なし」に寄りやすい。**幅を固定してから** 間隔をいじる順序が重要。
3. W+H の現行係数では H が過剰。W を主役にするなら **γ, ρ をさらに弱める** か、H なしで W を調整する。

### morphology 上の目標（W に特有）

- stripe の **太さが `(f,k)` を動かしてもほぼ一定** に見える（plateau B≈1）。
- 巨大な **単一 skeleton 成分** が支配しない（`longest_component_fraction` 低下）。
- 分断された成分に **3 股分岐**（skeleton 赤）が残る — 孤立ダッシュのみではない。

### 画像での確認

`artifacts/pit_step_eval/step5_pit_iv_bistable_width/` の `final_fields.png` / `final_skeleton.png` を baseline と並べる。

- fields: 均一な太さの worm / 曲線が多数、1 枚の網ではない。
- skeleton: 赤い 3-arm fork が複数成分に分散、白線が画面一端から他端まで1本、ではない。

## 成功条件（提案 W）

[`pit_model_evaluation.md`](pit_model_evaluation.md) の指標を、W の文脈で次のように読む。

| 指標 | W 導入で期待すること |
|------|----------------------|
| `longest_component_fraction` | baseline より **明確に低下**（例: 0.8 → 0.3 台） |
| `binary_coverage` | **極端な全滅・過密** を避け、baseline と同オーダー（~0.30） |
| `branch_density` / `branch_per_component` | **0 ではない**（分岐を殺していない） |
| `mean_segment_length` | 必要に応じて低下するが、極端に短い **枝なし** 断片だけ、は避ける |

W は単体でも成功しうる。H や M は **上乗せ** であり、必須ではない。

## まとめ

- **問題**: `(f, k)` が stripe の **幅** を「やわらかいモード」として変え、topology（分岐・適度な伸長）へのパラメータ探索を妨げる。
- **提案 W**: `λ B(1−B)(B−β)` で B を **0/1 双安定** にし、幅 ~ `sqrt(dB/λ)` を **`(f,k)` から切り離す**。
- **結果**: 被覆 ~0.31 のまま、巨大迷路を分断し、**3 股分岐を保持** — H 単体や cubic 対症療法では得にくい組み合わせ。
- **実務**: まず **step5 W 単体** で `λ, β` を触り、必要なら弱い H（step5b）や M（step5c）を足す。H は W の効果を潰しやすいので弱めに。

関連: 間隔・長さスケールは [`pit_type_iv_local_inhibitor_concept.md`](pit_type_iv_local_inhibitor_concept.md)、被覆フィードバック M は同 doc の Step 5 追補および [`pit_model_evaluation.md`](pit_model_evaluation.md) の Step 5 節。
