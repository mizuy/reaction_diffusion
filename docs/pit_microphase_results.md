# 一つの非局所モデルで I → IIIL → IV_B → IV_V を表す

2026-09-11。[モデルの式](pit_mechanochemical_transition_concept.md#11-四形態を一つの場で扱う非局所相分離モデル2026-09-11追加) / [検証計画と暫定判定基準](pit_microphase_protocol.md)。

**今回の範囲では「一つのモデルの一つの操作パラメータを変えて、四形態を順に通る経路」は得られた。** 前の場を引き継いだ順方向計算であり、四枚の図を別々の設定で作ったものではない。ただし、すべての条件で同じ境界を持つ四つの相が必ず現れること、臨床の四分類と同一であることまでは示していない。

同一領域、同一不均一場、同一の式と係数を使い、前の場を引き継ぎながら平均量mだけを増加させた。下表は10点の系列からの代表点。全10点と未分類の遷移点は隠さず保存している。

| I | −0.55 | 0 | 1.00 | 0 | 0.033 | 0.40 |
| IIIL | −0.15 | 0.50 | 1.17 | 0 | 0.052 | 2.50 |

## 一つのモデルで変えるもの・固定するもの

式は、短距離の界面費用と長距離の粗大化抑制を競合させる非局所相分離である。

\[
\partial_tu=\Delta(u^3-u-\epsilon^2\Delta u+\eta h)-\alpha(u-m),
\qquad\langle u\rangle=m.
\]

- 唯一の操作量: \(m=-0.55+0.80p\)。mは平均形態秩序量であり、実測の上皮/間質比に較正した値ではない。
- 固定係数: epsilon=1、alpha=0.025、eta=0.08、hの物理相関長3。
- hは固定の平均0・標準偏差1の平滑ランダム場。Type別の領域指定やpに依存した切替はしない。
- 観測は全mでu>0。係数だけでなく観測閾値も固定。
- 主計算: 周期領域128×128、dx=1、dt=0.4、各mで2500 step。mの変更時だけ平均量を注入し、保持中は保存する。

界面費用に対する非局所的抵抗と不均一性を間質側の作用に対応させるのは、今回の現象論的仮説である。上皮細胞・間質細胞・管腔を個別に解いた力学実証ではない。モデル形式はOhta–Kawasaki型であり、その大腸pitへの適用が今回の提案である。数学的背景は親conceptの文献リンクを参照。

## 検証で維持されたもの

### 長時間保持

各mの場を保存し、同じm・同じ式でさらに10000 step保持した。四つの代表形態だけでなく、10点の暫定ラベル列は変わらなかった。

代表IV_B（m=0）では分岐数5、最大成分比約0.147を維持。保持終了時の右辺RMSは約1.7e−7。代表IV_V（m=0.2）では分岐数19、最大成分比約0.950を維持し、右辺RMSは約1.0e−9となった。保持の最後20%の二値画像変化率はIV_Bで約0.0061%、IV_Vで0%。全10点では最大約0.049%。

これは有限時間内で安定した/ほぼ停止した形態であることを支持する。無限時間安定性や大域エネルギー最小の証明ではない。

### 時間刻み・空間刻み・閾値

同じ保存場から、dt=0.4で5000 stepとdt=0.2で10000 stepを比較し、保持する物理時間を揃えた。4代表点の暫定ラベルはいずれも一致。二値画像の差は最大約0.0061%。

格子を128²から256²へ、dxを1から0.5へ変更し、**物理領域128は固定**した。同じuとhをFourier補間して再緩和した。4代表点はI/IIIL/IV_B/IV_Vを維持。幅中央値の差は最大約6.1%、IV_Bの分岐検出数は5→4で、分岐数そのものには格子依存が残る。これは代表状態の精度検証で、全遷移境界の格子収束を確認したわけではない。

観測閾値を−0.1/0/+0.1に変えても、4代表点のラベルは維持された。IV_Bの分岐数は4/5/4。

### 初期配置と不均一性の変更

seedは初期ゆらぎと固定不均一場の両方を変える。seed 7の他に1と42を試した。

- seed 1: 元のm刻みで四形態を順に含んだ。IV_B代表はm=0.05。
- seed 42: 元の粗い刻みではIV_Bを検出できなかった。保存済みm=0.05から、mを0.01刻みで増加させる追加計算を行い、m=0.07/0.08にIV_Bが現れた。m=0.07の骨格長/幅p90は約10.54、最大成分比約0.271、分岐数3。m=0.08では約10.71、約0.334、分岐数5。
- seed 42の追加経路はm=0.25まで再計算した。異なる計算経路の途中を画像として貼り合わせてはいない。ただし、この刻みの細分化は初回結果を見た後の追加探索であり、事前指定の独立検証とは区別する。

したがって、四形態の経路がseed 7の一例だけというわけではない。一方、IV_Bのm範囲と遷移位置は配置・履歴で変わり、共通の境界値は未確立である。

## 維持されなかったもの・限界

### 逆方向の経路

高mから低mへ動かすと、網状構造が低mまで残る。順方向と同じ境界で四形態を逆順に通ることは確認できなかった。独立初期化でもIV_Bが現れるm帯は変化した。

これは履歴依存性や複数の準安定状態と整合するが、有限時間・有限刻みでの計算なので、真の平衡ヒステリシスと断定しない。

### 広い視野での有限長

dx=1のまま領域を192²へ広げた別の不均一配置では、I/IIIL/IV_Vは現れるものの、IV_Bの厳しい「骨格長/幅p90≤12」を満たさなかった。mを細かくしても、分岐が増えるm=0.07付近でp90が約14.6となり、失敗を解消できなかった。

領域サイズとhの実現値が同時に変わる比較なので、原因を有限サイズ効果だけに限定することはできない。**全領域サイズ・全配置で長すぎるpitを防げるという主張は未達。**

### 追加候補でのトレードオフ

上記失敗を受け、hの強さを固定値eta=0.12/0.16とした別経路を探索した。各経路内で変えたのは依然mだけである。

- eta=0.12の192²領域では、I→IIIL→IV_B→IV_Vを含む経路が得られた。m=0のIV_Bで分岐数12、最大成分比約0.12、骨格長/幅p90約10.1。
- しかし128²の別seedでは、初期がI基準を外れる例やIV_Bの有限長基準をわずかに外れる例があり、すべての配置を一つのetaで安定して満たしたわけではない。
- eta=0.16では初期から形がやや伸び、Iを飛ばす例があった。

この追加探索を、最初に固定したeta=0.08の独立検証に混ぜて合格率を上げることはしない。結果ビューには別候補として収録した。

### 不均一性の役割

eta=0の比較では、低mで模様が生じない状態や、分岐より長い管状が優勢な状態があり、同じ四形態経路を満たさなかった。ただし初期が低振幅ノイズであるため、核形成の困難さも含む比較である。

固定不均一性は有限の構造を保つ役割を持つ可能性がある。実際の間質不均一性がこの項で表せるか、hへの模様の追従がどの程度かは、今後の生物学的検証が必要である。

## 「相転移」として現時点で言えること

![秩序量の変化](../artifacts/pit_microphase/summary/order_parameters.png)

mに対して、伸長・分岐・最大連結成分比が変わり、幅の変化は比較的小さい。これは**同じモデル内の形態状態の系列と、連結性の転移候補**を示す。

一方、I→IIILは滑らかな変形でも説明できる。IV_B→IV_Vには連結性の大きな変化があるが、複数サイズでの臨界挙動や有限サイズスケーリングは未解析。四分類が四つの独立した熱力学的相であることは証明していない。

臨床Typeとの対応も、プロジェクト内の形態目標に対する暫定分類であり、臨床画像による盲検評価・定量校正は未実施。ここでのIV_Vは表面の迷路/gyrus様模様で、3Dの組織学的villous構築を再現したものではない。

## 次に優先する検証

まず臨床画像のpit幅・枝長・成分長分布で、今回の形態判定の許容範囲を校正する。その上で、alphaと固定不均一性の強さの小さな領域について、各領域サイズ・複数の配置に共通する1次元のm経路が存在するかを探索する。成分の長さを計測して切るルールは導入しない。
