# 独立初期化による形態選択の検証

2026-09-15。親テーマと候補式: [concept §12](pit_mechanochemical_transition_concept.md)。本書は新しい検証計画であり、完了結果ではない。

## 主判定

同一の式、固定係数、一つの外部操作量により、独立したランダム初期条件からI→IIIL→IV_B→IV_Vの順序を持つ共通のパラメータ区間が得られるか。画像配置の一致は求めず、形態・幅・有限長・非配向性の再現を求める。

各形態について探索で選び、検証前に固定した連続3点以上の操作量を用いる。各点で検証seed 20個中18個以上が目標形態となることを暫定的な工学上の採用基準とする。これは「必ず」の証明でも90%以上の母成功率の統計的保証でもない。失敗数と二項比率の区間推定を報告する。seedごとに形態に合うパラメータ点を選び直さない。点間の連続区間の存在は追加の細分化で確認する。

## 初期条件を分離する

- すべての操作量を時刻0から固定。初期場、補助場とも前段階を引き継がない。
- 現モデルは平均mに平均0のノイズ。標準偏差0.01、0.05、0.20を別々に比較する。
- 二場候補は一様定常解に同じ3段階の摂動。白色と相関長を持つノイズを共通規則で用い、形態を描き込まない。uとvの乱数系列を分離する。
- 現モデルのhは初期ノイズと別seedにする。まず同じhで初期seedを変更し、次にhのseedを変更する。h=0も独立の対照とし、h=0だけで成立しない場合は不均一性依存を明記する。
- 完全一様場は対称性から模様が出ない場合があるため、無摂動を必須合格条件にはしない。

## 探索と検証

探索seedは1、7、42。検証seedは100〜119とし、検証結果を見て係数を変更した場合は再び探索扱いに戻す。初期ノイズ振幅・相関ごとの成績を混ぜて平均化しない。

現モデルの開始設定はepsilon=1、alpha=0.025、eta=0.08、相関長3、m=-0.55〜0.25。既存の独立seed 7は探索データとして利用する。m刻みの細分化も探索として区別する。

二場候補では先に一様解の安定性と有限波数の成長を解析する。四形態の存在を仮定せず、全点を画像で確認する。b・g探索後にgとbの検証点を固定する。四形態に異なる係数を割り当てない。

## 形態と時間・領域

旧protocolの形態指標を出力するが、自動分類だけで合否を決めない。特にIIILは「Iではない非分岐形」を受け入れる可能性があるので、短管の実画像を確認し、探索段階で長さの下限を固定してから検証する。空場や太いblobを除外し、基準幅は探索Iから一度決めて全検証に共通とする。検証seedごとに基準幅を選び直さない。

有限成分長/幅、分岐密度、幅、配向性、周期連結性を併記。IIILとIV_Bでは長い管に少数の枝があるだけの例を除く。

初期評価時間Tを探索で固定し、T・2T・5Tで形態維持と変化量を確認する。長時間の観測だけで無限時間安定とは呼ばない。dt半減、同じ物理領域でdx半減、同じdxで領域長を1.5倍・2倍とする確認を行う。大領域でも少数の最長成分だけでなく長さ分布が維持されるか調べる。

continuation、逆方向、別の完成模様からの開始は副次的な吸引域の検査とする。これらの差だけで独立ランダム初期化の成功を撤回はしないが、履歴依存の範囲を報告する。

## 採否と保存

現モデルの共通形態帯が再現すれば維持する。不均一場に強く依存する場合はその制約を明記し、均一系の自発的パターン形成と区別する。次候補は同じ条件で比較し、未分類点と失敗を残す。

新計算の出力先は `artifacts/pit_independent_initialization/`。設定、初期seed、hのseed、初期条件の種類、保存場、時系列、全点の画像、連続量と暫定ラベルを保存する。結果を見て成功したseedだけ残すことは禁止する。
