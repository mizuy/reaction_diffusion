# Gray-Scott 経路掃引 v3 候補2: 拡散の空間ゆらぎ・非等方性で Type IV branching の Y 分岐は増えるか

結論を先に: **増えない（有意差なし・見た目も変わらない）**。v2 の経路・滞留・dB/dA=0.5 を固定したまま、拡散係数の静的ノイズ (a)、拡散テンソルの弱い非等方性 (b)、f(x,y) の弱いゆらぎ (c) を計 33 条件・47 run（各 run で labyrinth 滞留中 3 時点 = 141 サンプル）試したが、strict Y 分岐（3 腕各 ≥8 px）は v2 基準 **11.1 ± 3.2**（5 シード, 6–16）に対し最良条件でも **13.9 ± 2.9**（一様非等方 r=1.3, 5 シード, Welch p=0.10）で、端点・骨格成分・オイラー数は不変。振幅を上げると Y 分岐が増える前に他相（Type III の短 worm、villous の反転）が壊れる。**PR は作らず**、コードはブランチ `cursor/gs-sweep-anisotropic-diffusion`（base: `cursor/gs-path-sweep-video-58b1`）に push のみ。動画・比較画像の media 成果物は作っていない。

- 対象コード: `src/sweep_video.py`（上記ブランチ、commit `dc3cf6d`）。オプション未指定なら v2 と同一動作（`base_s11` が exp8 v2 の 7/6/8 を再現）。
- 実験記録（全 run の json/log/png/npz, 統計表）と比較画像（v2 基準 2 シード vs 一様非等方 2 シード vs 方位場非等方、step 86000、Y 分岐に緑丸）は別途。

## 1. 実装（`sweep_video.py`）

| 項目 | 内容 |
|---|---|
| 可変・非等方拡散 | `∇·(D(x)∇u)` を 9 点ステンシルの **保存形**（ペア重みを隣接 2 画素で平均）で離散化。テンソル `D=[[Dxx,Dxy],[Dxy,Dyy]]` に対しペア重み `w_x=0.3Dxx−0.1m, w_y=0.3Dyy−0.1m, w_pp=0.05m+0.15Dxy, w_pm=0.05m−0.15Dxy`（`m=tr D/2`）。等方一様なら repo の `KERNEL` と一致（誤差 2e-8）、解析解との相対誤差 0.3%。境界は `filter2D` と同じ REFLECT_101 |
| (a) 拡散ノイズ | `d(x,y) = d·(1 + amp·n)`, n はガウス平滑した単位分散ノイズ（相関長 σ px, ±2σ でクリップ）。対象 `a` / `b` / `ab`（同一場） |
| (b) 非等方性 | **平均保存** `(d_par+d_perp)/2 = d`, `d_par/d_perp = ratio`。方位 θ は一定角（`uniform`）または平滑ランダムなネマティック方位場 `θ = ½·atan2(s, c)`（`field`, 相関長 σ_θ）。対象 `a`/`b`/`ab` |
| (c) f ゆらぎ | `f(x,y) = f(s) + amp·n`（相関長 σ, ±2.5σ クリップ） |
| 安定性 | 陽解法 dt=1 で市松モードの増幅率は `1 − 4(w_x+w_y)`。dA=1 で係数が 1.25 倍を超えると不安定になるため、`max(w_x+w_y) > 0.45` の種については拡散項を自動で 2 サブステップに分割（v2 既定では発動しない） |
| CLI | `--diff-noise-amp/-sigma/-target/-seed`, `--aniso-ratio/-mode/-angle/-sigma/-target/-seed`, `--f-noise-amp/-sigma/-seed` |

## 2. 実験手順

v2 プリセット（120 000 step, 256², seed 7, noise seed 11）をヘテロ媒質付きで**最初から**流し、exp8 と同じ step で計測: Type I 12 000、Type III 62 000、IV branching 82 000/86 000/90 000（s=0.66 滞留）、villous 118 000。指標は v2 と同じ `topo_all.py` 相当（Otsu 二値 → Zhang–Suen 細線化 → 枝刈り; `junc3` = 3 腕各 ≥8 px の分岐クラスタ数、端点、骨格成分、オイラー数 n_fg−n_bg）。v2 基準は noise seed 11–15 の 5 run で分散を出した。

## 4. 副作用（4 相への影響）

- **一様非等方 r≤1.3 (`ab`)**: Type I は spots のまま（n_fg 172–181）だが縦横比中央値が 1.11 → 1.20 とやや楕円。Type III、villous（n_bg 210–216, 暗成分 asp 1.12–1.22）は無傷。唯一「無害」な条件だが効果もない。
- **方位場非等方 (`ab`)**: 4 相は保たれる。r=1.5/σ_θ=48 では junc3 が 6 に減る（大きな方位ドメイン内で平行 stripe になる）。
- **一種のみの非等方性（A のみ・B のみ）**: 方向ごとに実効 dB/dA が変わるため致命的。B のみ r=1.5 は Type I が出ず（最初から worm）、villous も反転しない。A のみ r=1.3 も Type III が n_fg 33、villous 不成立。
- **dA ノイズ ≥20%**: 相が空間的に混在する（低 dA 域が先に labyrinth/holes 化）。Type III の n_fg 168 → 103–74、labyrinth の端点 38 → 51–58、Euler −32 → −2〜−14、villous は 30% で反転せず（n_bg 135–137, 判定 labyrinth）。Type I も密度ムラ。「局所的に villous 寄りの連結網」は出るが Y 分岐ではなく相の斑になる。
- **dB ノイズ 30%**: Type I は保つ（n_fg 223）が Type III が短くならず n_fg 99、labyrinth の端点 48・骨格成分 19 と分断的。
- **dA+dB 同一場 20%**（局所的な長さスケール変調）: junc3 7.3 で基準以下。
- **f ゆらぎ**: ±0.001 でも villous の穴数 211–220 → 166–185（f が低い領域が反転しない）。±0.0015 で 156、±0.002 では holes 判定が 28 フレームのみ。Type III も n_fg 110–134 と長い worm 混じり。junc3 は増えない。
- **数値スキームの注意**: 一様媒質で A 拡散だけ 2 サブステップにした対照（`ctrl_sub2`）でも Type I→III 変換が大きく遅れた（worm 70 フレーム、62 000 step でまだ spots 判定）。準安定 hex 格子の崩壊時刻は数値誤差レベルの摂動に敏感で、v2 の Type III タイミングは「その数値スキームでの再現」であることを示す。junc3 は 9.7 で不変。

## 5. 結論と示唆

1. 候補 2（拡散の弱い非等方性・空間ゆらぎ）は **Type IV branching の Y 分岐を増やさない**。256² あたり 10〜15 という上限は v2 レポート exp9 の結論（経路上どこでも 2–14）と一致し、dB/dA=0.5 の GS labyrinth の性質である。媒質の不均一は Y 分岐ではなく「相の空間的混在」や「stripe 方向のドメイン化」として現れる。
2. 弱い一様非等方性 r=1.3 は無害だが +25%（有意でない）に留まり、動画にする価値がない。したがって v3 動画・phases・比較の media 成果物は作成せず、PR も作成していない。コード（保存形の可変・非等方拡散オペレータ、f(x,y) ゆらぎ、CLI）はブランチに残してあり、別ワーカーの候補 1（dB/dA 変更）や、局所的な (f,k) 場の演出（例: villous 寄りのパッチ）を試す際に流用できる。
3. 樹枝状分岐に向けた次の候補（本タスク範囲外）: (i) 候補 1 の dB/dA を下げて先端分裂（tip splitting）が起きる領域を探す、(ii) 実画像の Type IV branching は「連結した明い網 + 細長い暗溝」なので、labyrinth ではなく holes 側の手前（s≈0.75–0.8, exp6 `jumphi075/080` で junc3 11 まで出ている）を暗溝が丸くなる前に止めて明相の網の分岐を数える、(iii) 反応拡散以外（既存の力学的座屈モデル）。
