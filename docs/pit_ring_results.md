# 新しい管腔–上皮モデルの初回計算結果

2026-09-11。[concept](pit_mechanochemical_transition_concept.md) / [protocol](pit_ring_protocol.md)。

**円形→短管→Y字様の局所平衡が得られた。一方、増殖要求を順に上げると長いpitの枝に留まるため、過伸長問題の解決や四形態の相転移の実証には未達である。**

## 実装して計算したもの

管腔を囲む上皮輪郭の面積・周長・曲げエネルギーと、間質を近似する局所的な弾性支持を用いた。上皮余剰周長要求gを変え、同じエネルギーの局所極小を探索した。画像処理による切断・形態別の長さ上限・Y字テンプレートは使用していない。

これは2Dの単一腺口で、星状閉曲線のFourier近似。全間質の弾性PDE、複数腺口間の相互作用、合流、3D villous構築は未実装。BFGSの反復数は生物学的時間ではない。

基本値: 初期半径1、面積剛性40、周長剛性20、曲げ剛性0.03、主系列の間質支持剛性0.3。物性値は仮定した無次元値である。

## 主系列の実測

間質支持0.3、seed 7、24モード・384積分点、独立初期化。

| g | 管腔面積/初期面積 | 伸長比 | 優勢角度モード | 形態の目視所見 |
|---:|---:|---:|---:|---|
| 0 | 1.0003 | 1.00 | 0 | 円形 |
| 0.025 | 1.0047 | 1.32 | 2 | 軽い楕円 |
| 0.05 | 1.0047 | 1.58 | 2 | 短い楕円 |
| 0.10 | 1.0047 | 2.02 | 2 | 短管 |
| 0.20 | 1.0042 | 2.46 | 2 | 非対称な短管 |
| 0.35 | 1.0049 | 3.35 | 2 | 細長い管状 |
| 0.50 | 1.0055 | 2.01 | 3 | 屈曲・分葉 |
| 0.70 | 1.0059 | 1.16 | 3 | Y字様 |
| 0.90 | 1.0068 | 1.06 | 3 | Y字様 |

伸長比は管腔内部の面積分布の共分散から計算。Y字形では複数方向に広がるため伸長比が1に近くても円形ではない。臨床Typeの確定ラベルは付けていない。

## 円形の不安定化は検出できた

各gで半径だけを緩和した円形定常解について、非円形変形方向のHessian最小固有値を求めた。以下の区間で正から負に変わった。

| 間質支持剛性 | 円形が不安定化するgの区間 | 最初に不安定になるモード |
|---:|---:|---:|
| 0.03 | 0.0050–0.0055 | 2（楕円化） |
| 0.3 | 0.0110–0.0115 | 2（楕円化） |
| 3.0 | 0.0370–0.0375 | 3（多葉化） |

![円形安定性と履歴依存性](../artifacts/pit_ring/validation/stability_and_history.png)

この結果は**縮約モデル内の円形の形状不安定性**の証拠である。組織全体の相転移、四つの独立相、臨床病変の進行順序を示したものではない。強い間質支持では楕円化を飛ばす可能性がある。

## 成功扱いにできない理由

### 1. 長いpitの局所平衡が残る

![履歴比較](../artifacts/pit_ring/validation/history.png)

上段は独立初期化、中段はg増加、下段はg減少。比較のためgはすべて左から昇順で表示した。

gを増加させて前の解を引き継ぐと、g=0.5/0.7/0.9で伸長比が5.13/7.29/9.62となった。独立初期化のY字様形態だけを掲載すると、この重要な失敗を隠してしまう。

g=0.7では増加経路の細長い解のエネルギー0.71854が、独立初期化のY字様解0.72690より低い。したがって、単に「もっと十分に緩和すれば必ず分岐する」とは言えない。いずれも大域最小の証明はない。

### 2. 幅は一定ではない

同じ物理座標を128 pixel/初期半径で描画し、骨格上の距離変換から測った幅中央値は、g=0で1.89、g=0.1で1.29、g=0.7で0.66、g=0.9で0.56だった。円形の骨格化にはラスタ依存性があるが、細くなる傾向は明瞭である。面積をほぼ固定して周長を増やすため、幅が減少する逃げ道が残る。

64/128 pixelで測定値を保存した。既存の厳密3枝検出器では、この主系列はすべて0判定だった。したがって、Y字様という記述は目視形態であり、既存IV_B評価の合格ではない。骨格処理・枝検出の校正も必要である。

### 3. 分岐域は解像度依存性が残る

![Fourier次数比較](../artifacts/pit_ring/validation/refinement.png)

24/36/48モード、384/576/768積分点で比較した。g=0.1の伸長比は約2.015で一致。g=0.7のY字様形は残るが、g=0.5は48モードで管状に移り、g=0.9も非対称性が変化した。g=0.5のエネルギーは0.56442→0.54175→0.48530で、計算精度への収束は不十分である。

星状・1次モード除外の制約も残るため、単純な形態の変化以上の主張は避ける。

## 数値検証とアブレーション

- 初回探索27条件、追加精細スイープ9条件、検証73条件を実行。検証73条件はseed 1/7/42、増加・減少経路、次数増加、面積拘束除去、摂動後再緩和を含む。
- 検証73条件すべてで最大勾配残差が1e-6未満。最小Hessian固有値の最悪値は−8.97e-6で、−1e-4より負の解はなかった。これは有限次元近似内での検査であり、大域安定性や連続体極限の証明ではない。回転対称性由来のほぼゼロの固有値も含む。
- 主系列9解に微小摂動を加えた再緩和で、最大径の相対変化は最大5.07e-5。局所平衡が単なる途中の画像ではないことを確認した。ただし長時間の物理ダイナミクスを計算したわけではない。
- 面積拘束を外すと、g=0.1ではほぼ円形のまま面積比1.208、g=0.35では1.810へ拡大した。面積拘束が低gでの形状変形を促していることを支持する。高gでは拘束なしでも非円形になるので、分岐の必要条件とまでは言えない。
- 今回の主系列では接触エネルギーは0だった。有限な形態は主に面積・周長・曲げ・局所支持で決まり、導入した軟接触項の効果はまだ検証されていない。
- 円の面積・周長・曲げエネルギーの解析値、接触を含む勾配の有限差分照合、緩和のエネルギー降下と円形回復の3テストが通過。

[面積拘束あり／なしの画像](../artifacts/pit_ring/validation/area_ablation.png) / [seed比較](../artifacts/pit_ring/validation/seeds.png)

## 次のモデル変更を絞るための結論

局所支持＋有限管腔は、円形の不安定化と有限な非円形解を作る。ただし、強制的な長さ切断を外すだけでは過伸長問題は消えない。次は**上皮壁の厚み・極性と、共有間質を介した非局所的な抵抗**を導入し、長い管状の平衡枝が不安定になるかを検証する。形態ごとに長さ上限を切り替える方法には戻さない。

villousまでの検証には、単一の閉曲線という固定トポロジーを外し、複数腺口や表面の立体構築を計算するモデルが必要である。

プロジェクトディレクトリから:

```bash
.venv/bin/python src/simulate_pit_ring.py --output artifacts/pit_ring/exploration --points 128 --modes 10 --growth 0 0.1 0.2 0.35 0.5 0.7 0.9 1.2 1.5 --maxiter 1000
.venv/bin/python src/simulate_pit_ring.py --output artifacts/pit_ring/refined --stroma 0.3 --modes 24 --points 384 --growth 0 0.05 0.1 0.2 0.35 0.5 0.7 0.9 1.2 --hessian
.venv/bin/python src/evaluate_pit_ring.py
.venv/bin/python src/summarize_pit_ring.py
.venv/bin/python -m pytest tests/test_pit_ring.py -q
```
