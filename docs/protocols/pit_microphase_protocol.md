# 非局所相分離モデルによる四形態系列の検証

2026-09-11。親テーマ: [pit_mechanochemical_transition_concept.md](../concepts/pit_mechanochemical_transition_concept.md)。ゴール: [pit_pattern_goal.md](../pit_pattern_goal.md)。

単一閉曲線から離れ、管腔・溝に対応する形態秩序場を面全体で計算する。界面の費用と、間質の長距離抵抗に対応する非局所費用を競合させる。平均秩序量mだけを連続的に変える。形態別係数、長さ検出による切断、合成図形の挿入を禁止する。

このモデルは形態の現象論であり、上皮・間質・管腔を独立に解く3D力学モデルではない。非局所相分離による形態系列が成立するかを最初に検証する。

固定ノイズから作る等方的な間質不均一場の有無を比較する。不均一場は全mで固定し、pit形状から生成しない。平均量mは低被覆から高被覆へ増加する一つの操作軸とする。

1. 探索: 非局所抵抗と不均一性の固定値を選び、mだけを動かす系列を比較。
2. 同一場を引き継ぐ順方向、逆方向、独立初期化を区別する。
3. 初期ゆらぎ・不均一性のseed、保持時間、刻み、領域サイズ、画素幅を変えて再検証する。
4. 全系列同じ二値化閾値を用い、幅・連結成分長/幅・分岐・連結性・配向性を計測する。
5. 局所平行stripeや過伸長をIVとして合格にしない。自動ラベルと目視を併用し、既存評価器の既知の枝検出問題も記録する。
6. 四形態があること、同じ1次元経路で順に現れること、各形態が保持されること、臨床画像に近いことを別々に評価する。
7. 均一mの系列を主評価とし、空間勾配の一枚絵は成功の代用にしない。

主出力: `artifacts/pit_microphase/`。数値解とパラメータをNPZ/JSON、観測量をCSV、画像をPNG、操作できるビューをHTMLとして保存する。

## 探索後に固定した候補と検証判定

seed 7の探索後、alpha=0.025、epsilon=1、eta=0.08、相関長3、m=-0.55〜0.25を候補として固定する。以下のseed・保持・刻み・解像度検証では係数を再調整しない。探索結果と独立検証を区別する。

形態の暫定的な操作分類（臨床的に校正された診断器ではない）:

- 共通: I時の幅中央値に対する比0.6〜1.5、配向度<0.5。
- I: 分岐0、成分伸長比p90<1.8、成分骨格長/幅p90<2。
- IIIL: 分岐数が基準視野128×128あたり3未満、成分伸長比p90≤3.5、骨格長/幅p90≤6。
- IV_B: 分岐数が基準視野あたり3以上、最大成分比<0.4、骨格長/幅p90≤12。有限の分岐群。
- IV_V: 同じ分岐条件を満たし、最大成分比≥0.4、または背景の周期的連結成分数が基準視野あたり6以上。非配向の連結迷路。
- それ以外はtransition/unresolved。無理に四種類へ押し込めない。

骨格長は画素数×dxの近似なので斜め方向の系統誤差がある。伸長比は周期座標で計算するが全域連結相での解釈は避ける。分岐は冗長な斜め辺を除いた骨格グラフで、物理長3以上の枝が3本以上出る接合を数える。二値化は全mでu>0に固定し、検証では±0.1も調べる。

系列の評価は四形態の順序が存在することと、すべての点を四形態だけで説明できることを別々に報告する。間にtransition/unresolvedがあればそのまま表示する。
