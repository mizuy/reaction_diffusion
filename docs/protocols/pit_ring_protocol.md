# 管腔–上皮輪郭モデルの初回シミュレーション

親文書: [concept](../concepts/pit_mechanochemical_transition_concept.md)。2026-09-11。

目的: 上皮の余剰周長要求だけを増やし、有限管腔の円形安定性と変形後の局所平衡を数値的に調べる。四分類の再現成功を仮定しない。

実装上の縮約は親文書§9.3に記載する。初回は単一管腔であり、腺口間の合流・villous構築は対象外。ランダムな微小Fourier係数から初期化し、Type別の初期形状や長さ切断を使わない。

- 無次元初期半径1。面積剛性40、周長剛性20、曲げ剛性0.03を初期探索値とする。これらは組織から推定した物性値ではない。
- 上皮余剰周長要求gと間質の局所支持剛性をスイープする。各間質条件内ではgだけを変える。
- 独立初期化と増加・減少continuationを区別する。continuationでは数値対称性に閉じ込められないよう微小擾乱からの再緩和も行う。
- エネルギー最小化は過減衰系の平衡探索であり、最適化反復数を生物学的時間とは解釈しない。
- 面積、周長、伸長比、円形度、優勢角度モード、輪郭の最小半径、勾配残差、最小Hessian固有値、最適化収束状況を出力する。
- 初期探索後、複数seed、Fourier次数・積分点数増加、微小擾乱後の再緩和、面積拘束を外すアブレーションで確認する。
- 有限長は表示枠では制限しない。同じ物理座標スケールの輪郭画像を出力し、表示枠のクリップがないか確認する。
- 負のHessian固有値・未収束・強い最高次モード依存がある解は安定な形態とは報告しない。
- 閉曲線はstar-shapedという制限があり、複雑な非星状分岐やトポロジー変化は生成できない。有限性・分枝の結論はこの近似の範囲で述べる。

成果物: `src/pitpattern/models/simulate_pit_ring.py`、`artifacts/pit_ring/` のCSV/JSON/輪郭配列・比較画像、および `pit_ring_results.md`。
